# Salt Analysis Chemistry Dashboard

- `index.html` — the quiz app.
- `questions.json` — the question bank. Edit this file (via the GitHub
  web UI or locally) and commit — Netlify redeploys automatically, and
  every visitor's next page load picks up the change. No need to
  touch `index.html` or resend anything.

## Editing questions
Open `questions.json` on GitHub, click the pencil (edit) icon, change
a question/option/`correct` index, then "Commit changes" directly to
`main`. Netlify picks up the push and redeploys in under a minute.
